# Install Guide

This guide will help you install DeerAnalysis on your computer. The installation process is straightforward and should only take a few minutes.


## Windows

On Windows, DeerAnaysis is distributed a portable executable. Please just save the file `DeerAnalysis.exe` to a location of your choice and double-click it to run the program. You can also create a shortcut to the executable for easier access.


## macOS

On macOS, DeerAnaysis is distributed as a .app file. Please just save the file `DeerAnalysis.app` to your Applications folder and double-click it to run the program.
